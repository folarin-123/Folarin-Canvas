# Product photos

Place optimized product photos in this folder and reference them from `src/data/catalog.js`.
Use a relative public URL such as `image: '/products/ankara-wrap.jpg'`; optionally add
`detailImage: '/products/ankara-wrap-detail.jpg'` for a second view. Square or 4:5 images
work well, and the product visual reserves a 4:5 image area to avoid layout shift.
Keep images compressed and provide rights-cleared photos only.
